# Project Control Document v0.2

## Project
Ana (آنا)

## Current phase
Sprint 0 / Execution Initialization

## Objective
Build a B2B real-estate collaboration network that supports both supply-driven Listings and demand-driven Requirements, then turns discovery into protected cross-agency collaboration and real deal outcomes.

## Initial market
Najafabad, Isfahan; broader Isfahan expansion is conditional on density and evidence.

## Core product loop
Listing or Requirement -> Discovery -> Collaboration -> Controlled disclosure/negotiation -> Agreement -> Deal -> Commission outcome.

## Product principles
- Trust evidence before reputation score.
- Progressive information disclosure.
- Business-model flexibility through entitlements, not plan checks in features.
- Build small vertical slices and measure real behavior.
- Complexity must be justified by a current problem.

## Current non-goals
Microservices, Kubernetes, complex rules engine, AI/ML, independent search engine, payment processing, advanced reputation scoring, full CRM/ERP.

## Current critical risks
1. Trust vs information exposure.
2. Network liquidity/cold start.
3. Bypass/leakage between agencies.
4. Stale/duplicate/low-quality supply.
5. Informal tools may remain cheaper/easier for some workflows.
